# Source and data

Code is MIT licensed. Common policies and the WordPress/Discord foundations come from [Jobicy API Examples](https://github.com/Jobicy/jobicy-api-examples/tree/0ff8d59c56ba4aae94869c7ea6cd8af96f74fdee). Other integrations use the official Jobicy SDKs or MCP server.

Job listings, employer text and logos have separate ownership and [fair-use terms](https://github.com/Jobicy/remote-jobs-api#fair-use). Preserve original listing URLs and visible **Jobs powered by Jobicy** attribution in public interfaces. Feed synchronization must be hourly or less frequent.
